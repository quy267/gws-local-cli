Privacy policy

Last updated: 20 November 2026

gws-local-cli is a personal tool used only by its owner with the owner's own Google accounts.

What data it accesses

With the owner's consent, it reads and changes the owner's Google data in the services the owner connects: Gmail, Drive, Calendar, Sheets, Docs, Forms, Tasks, Slides, Search Console, Analytics and Tag Manager.

How the data is used and stored

  • Data is used only to carry out the owner's own requests on the owner's own computer.
  • Google sign-in tokens are stored encrypted on the owner's computer. No data is stored on any server run by this app.
  • Data is not sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

The use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions can be raised as an issue in this site's repository: github.com/quy267/gws-local-cli.
